# 譯名表

譯名以 **軟體世界（Soft-World）貴族版第 068 號《瘋狂大樓》中文說明書**為第一優先來源。掃描件由「骨灰集散地」說明書補完計劃於 2018 年完成（`manual/068-瘋狂大樓/`），第 35 頁附錄「選擇人物畫面的人物資料」給了七位主角的官方中譯，第 1 頁「話說從頭」給了 Edison 一家與怪物的中譯。

當年的代理商是**軟體世界**，不是松崗——CLAUDE.md 早期版本記為松崗，以掃描件為準更正。

## 15 個指令（verb）

手冊第八章「指令介紹」給的是語意說明，不一定等於畫面標籤。verb bar 是 5 欄 × 3 列的固定格位，中文標籤還要看實際像素預算，以下「verb 標籤」欄為草案，待實機排版驗證後定案。

| 原文 | 手冊語意 | verb 標籤（草案） |
|---|---|---|
| Push | 推、按（例如電源開關、門鎖） | 推 |
| Pull | 拉、從水中或牆上拉物品 | 拉 |
| Give | 給與，把物品給某人（選好物品後還要指定給誰） | 給 |
| Open | 打開，開門或櫃子，只限沒上鎖的 | 打開 |
| Close | 關上，和 Open 相反 | 關上 |
| Read | 閱讀，看標示（Sign）、海報（Poster）等 | 閱讀 |
| Walk to | 人物走動，走到畫面中任何地方；進出房間或走到螢幕外的地點也用它 | 走到 |
| Pick up | 拿起物品並攜帶，太重及固定者無法拿起 | 拿起 |
| What is | 物品顯示，游標移到物品上時物品名會出現在文句行 | 這是 |
| Unlock | 開鎖，把鎖住的門打開，必須擁有適當的鑰匙 | 開鎖 |
| New kid | 換人，切換行動角色（也可直接按 F1/F2/F3） | 換人 |
| Turn on | 打開電源（電視、收音機、暗房電燈等） | 開啟 |
| Turn off | 關掉電源，和 Turn on 相反 | 關閉 |
| Use | 使用物品表內的物品 | 使用 |
| Fix | 修理壞掉的電器，但要有適當的工具 | 修理 |

畫面上的排列（由上而下、由左而右）：

```
Push   Open    Walk to   Unlock    Turn on
Pull   Close   Pick up   New kid   Turn off
Give   Read    What is   Use       Fix
```

## 譯文風格

原作是黑色喜劇、B 級恐怖片戲仿，語氣要玩得起來，但不塞破壞 1987 年代感的流行語。人名、地名、物品名一律沿用上表，不即興改動。
